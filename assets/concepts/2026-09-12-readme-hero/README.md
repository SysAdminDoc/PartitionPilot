This folder records the correction that put one marketing hero at the top of the project README. It belongs to the existing PartitionPilot marketing pass for GitHub repository `R_kgDOS87h_A`; it is not a second project record.

## Selected direction

`readme-hero-final.png` is the selected safety-led direction. It keeps the approved storage-route mark, leads with the review-before-write promise, and uses the real partition workspace captured from the production WPF app on a private desktop. The product crop omits the application header and status bar so the artwork stays free of release numbers.

The same selected pixels are published as:

- `../../marketing/readme-hero.png` for the README.
- `../../social-preview.png` for repository sharing surfaces.
